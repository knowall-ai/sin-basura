== Overview

Sin Basura ("Without Trash") is a Nostr-based litter collection rewards program for El Salvador. The system incentivizes community members to collect rubbish by rewarding them with Bitcoin Lightning payments (sats) for verified collections.

=== Key Principles

* **Transparency** - All operations visible on Nostr relays
* **Decentralization** - No central authority controls the fund
* **Verifiability** - Local attesters verify collections in person
* **Instant Payments** - Lightning zaps for immediate rewards

=== Attester Role

Attesters are **local program managers** who:

1. **Verify collections** in person
2. **Pay collectors** via zap from the fund (using NWC)
3. **Purchase supplies** for collectors (gloves, picker arms, bin bags)
4. **Build community** and recruit new collectors

Attesters connect to the central fund wallet via Nostr Wallet Connect (NIP-47), giving them spending authority without custody of the full fund.

=== Attestation (kind 1985)

Posted by an authorized attester to verify a collection.

==== Successful Verification

The attester posts an attestation AND zaps the collection post. The attestation links to the zap receipt for audit trail.

[source,json]
----
{
  "kind": 1985,
  "pubkey": "<attester_pubkey>",
  "created_at": 1737215000,
  "tags": [
    ["L", "sv.sinbasura.verification"],
    ["l", "verified", "sv.sinbasura.verification"],
    ["l", "3", "sv.sinbasura.bags"],

    ["e", "<collection_event_id>", "wss://relay.damus.io", "root"],
    ["p", "<collector_pubkey>", "wss://relay.damus.io"],
    ["a", "30078:<admin_pubkey>:sinbasura-program", "wss://relay.damus.io"],

    ["zap", "<zap_receipt_event_id>", "wss://relay.damus.io"]
  ],
  "content": "Verified in person at Playa El Tunco. 3 bags confirmed. Zapped 30,000 sats.",
  "id": "<attestation_event_id>",
  "sig": "<signature>"
}
----

The optional `zap` tag links the attestation to the payment receipt, enabling full audit of verification → payment.

==== Rejection Reasons

[cols="1,2"]
|===
| Label | Description

| `duplicate`
| Same collection submitted multiple times

| `insufficient-proof`
| Photo does not clearly show collection

| `location-mismatch`
| GPS coordinates don't match photo

| `fraudulent`
| Evidence of fraud or manipulation

| `not-found`
| Collection not found at location
|===

=== Payout Calculation

[source]
----
Verified bags × Rate = Payout

Example:
3 bags × 10,000 sats = 30,000 sats
----

=== Payout Process (Attester-Initiated)

1. Collector posts collection proof (kind 1) with photo and location
2. Attester meets collector in person to verify
3. Attester posts attestation (kind 1985) with `verified` label
4. Attester zaps the collection post from the fund (via NWC)
5. Collector receives sats instantly to their Lightning address
6. Zap receipt (kind 9735) serves as payment proof

=== Community Top-ups

Other Nostr users can zap verified collection posts as additional tips:

* Tourists appreciating clean beaches
* Bitcoiners supporting the cause
* Local businesses
* Environmental supporters worldwide

These community zaps provide **bonus income** beyond the base rate, creating viral incentives for impactful collections.

== Security Considerations

=== Attester Verification

* Only pubkeys listed in the Program Definition can create valid attestations
* Clients MUST verify attester pubkey against program definition
* Invalid attestations should be ignored

=== Anti-Fraud Measures

* GPS coordinates required in collection proofs
* Photo metadata (EXIF) can be verified
* Attesters verify in person
* Rate limiting on collections per day per collector
* Community reporting of suspicious activity

=== Fund Security

* Initial funds protected by Rootstock smart contract
* Ongoing fund controlled by multi-sig (future)
* All transactions visible on Nostr and Lightning

== Glossary

|===

| Authorized local program manager who verifies collections in person, pays collectors via NWC, and purchases supplies

| Nostr event (kind 1) with photo and location evidence

| Nostr public key identifying a user

| Server that stores and distributes Nostr events

| Satoshis - smallest unit of Bitcoin (1 BTC = 100,000,000 sats)
