== Overview

Sin Basura ("Without Trash") is a Nostr-based litter collection rewards program for El Salvador. The system incentivizes community members to collect rubbish by rewarding them with Bitcoin Lightning payments (sats) for verified collections.

=== Key Principles

* **Transparency** - All operations visible on Nostr relays
* **Decentralization** - No central authority controls the fund
* **Verifiability** - Local attesters verify collections in person
* **Instant Payments** - Lightning zaps for immediate rewards

=== Technology Stack

[cols="1,1,2"]
|===
| Layer | Technology | Purpose

| Initial Funding
| Geyser + Rootstock
| All-or-nothing crowdfunding with smart contract protection

| Ongoing Donations
| Nostr Zap Goal (NIP-75)
| Continuous top-ups to the fund

| Operations
| Nostr events
| Transparent proof, attestation, payouts

| Payments
| Lightning Zaps (NIP-57)
| Instant micropayments to collectors

| Media Storage
| Blossom (NIP-B7)
| Decentralized photo proof storage
|===

==== Tag Definitions

[cols="1,2,1"]
|===
| Tag | Description | Required

| `d`
| Unique identifier for addressable event
| Yes

| `attester`
| Authorized verifier pubkey, relay, name
| Yes (1+)

| `rate`
| Millisats per unit (e.g., 10000 sats per bag)
| Yes

| `fund`
| Reference to the Zap Goal event
| Yes

| `geyser`
| Geyser campaign URL
| No

| `relay`
| Recommended relays for the program
| Yes (1+)
|===

  "id": "<event_id>",

==== Rejection Reasons

[cols="1,2"]
|===
| Label | Description

| `duplicate`
| Same collection submitted multiple times

| `insufficient-proof`
| Photo does not clearly show collection

| `location-mismatch`
| GPS coordinates don't match photo

| `fraudulent`
| Evidence of fraud or manipulation

| `not-found`
| Collection not found at location
|===

== Funding Model

=== Dual Pool Architecture

[source]
----
┌────────────────────────────────────────────────────────────────┐
│                    GEYSER ALL-OR-NOTHING                       │
│                    (Initial Launch Fund)                       │
│                                                                │
│   Goal: 5,000,000 sats                                        │
│   = 500 bags of rubbish collection                            │
│                                                                │
│   If goal met: Program launches with guaranteed runway        │
│   If goal missed: All donors refunded automatically           │
└────────────────────────────────────────────────────────────────┘
                              +
┌────────────────────────────────────────────────────────────────┐
│                    NOSTR ZAP GOAL (NIP-75)                     │
│                    (Ongoing Operations Fund)                   │
│                                                                │
│   Continuous donations via Nostr zaps                         │
│   No minimum, no deadline                                     │
│   Transparent balance visible to all                          │
└────────────────────────────────────────────────────────────────┘
----

=== Payout Calculation

[source]
----
Verified bags × Rate = Payout

Example:
3 bags × 10,000 sats = 30,000 sats
----

=== Payout Process

1. Client queries for verified attestations
2. For each verified collection, read bags count
3. Calculate payout amount
4. Send zap request (kind 9734) to collector's lnurl
5. Zap receipt (kind 9735) serves as payment proof

== Security Considerations

=== Attester Verification

* Only pubkeys listed in the Program Definition can create valid attestations
* Clients MUST verify attester pubkey against program definition
* Invalid attestations should be ignored

=== Anti-Fraud Measures

* GPS coordinates required in collection proofs
* Photo metadata (EXIF) can be verified
* Attesters verify in person
* Rate limiting on collections per day per collector
* Community reporting of suspicious activity

=== Fund Security

* Initial funds protected by Rootstock smart contract
* Ongoing fund controlled by multi-sig (future)
* All transactions visible on Nostr and Lightning
